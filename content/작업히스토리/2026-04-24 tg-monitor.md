## 구현 과정

### 1단계 — 프로젝트 초기 세팅
- `monitor.py`, `auth.py`, `config.yaml`, `requirements.txt` 생성
- Python venv 구성 및 telethon 설치

### 2단계 — Telethon 세션 인증
- `auth.py` 실행 → 전화번호 인증코드 입력 → 세션 파일 생성
- 인증코드 요청 과다로 Telegram Flood Wait 발생 (약 2일 소요)
- FloodWaitError 감지 및 대기 시간 표시 기능 추가

### 3단계 — 채널 연결 테스트
- `test_connection.py`로 4개 채널 접근 확인
- 각 채널 마지막 메시지 `@RRoy1015`로 전송 성공

### 4단계 — 카카오톡 연동 (kmsg)
- `kmsg` CLI 설치 (`~/.local/bin/kmsg`)
- macOS 손쉬운 사용 권한 부여
- 카카오톡 메시지 전송 테스트 성공

### 5단계 — monitor.py 실시간 모니터링 구현
- Telethon `events.NewMessage` 이벤트 핸들러 사용
- 키워드 감지 → `@RRoy1015`로 포워딩

### 6단계 — 기능 개선
- **포워딩 방식**: `send_message` → `forward_messages`로 변경
- **from 레이블**: 이미 포워딩된 메시지인 경우에만 채널명 표시
- **답장 형식**: 별도 메시지 대신 포워딩 메시지에 reply로 채널 출처 표시
- **중복 제거 TTL**: MD5 해시 + 24시간 TTL 방식으로 메모리 누수 방지
- **from 메시지 무음**: `silent=True` 적용
- **링크 미리보기 감지**: `MessageMediaWebPage`의 title/description도 키워드 검색 범위 포함

### 7단계 — 채널 및 키워드 확장
- 모니터링 채널 4개 → 48개로 확장
- 키워드 확장: `삼천당제약`, `삼천당`, `삼성전자`, `삼전`, `SK하이닉스`, `하이닉스`
